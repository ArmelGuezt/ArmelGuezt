# GitHub Profile V2.1 - Privacy Edition

## Manutenção

- O README apresenta competências profissionais e ilustrações de engenharia.
- O perfil não inclui listas de projetos, métricas de commits ou calendário personalizado.
- A geração local dos elementos gráficos não consulta a API do GitHub nem publica dados de atividade.
- Não envie credenciais ou informações confidenciais ao repositório.

## Gerar elementos gráficos localmente

```bash
python3 scripts/render.py
```

## Privacidade

- As configurações de visibilidade da conta e dos demais repositórios são independentes deste README.
- Arquivos removidos da versão atual podem continuar disponíveis no histórico Git.
